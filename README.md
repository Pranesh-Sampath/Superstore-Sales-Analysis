# 🛒 Superstore Sales Analysis (EDA)

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on a Superstore dataset to uncover key business insights related to sales, profit, discounts, and regional performance.

The analysis helps in understanding:
- Sales trends over time
- Profitability across categories
- Impact of discounts on profit
- Regional performance comparisons
